# Source and asset provenance

## Included

- Application modules and original vector drawings are project work under Apache-2.0. Fictional scenarios and demo vaults were independently written; they are not anonymized copies of personal notes.
- The dictionary's SVG is an original typographic title card, explicitly described as such. Bibliographic details are public facts linked to Oxford Reference. The short description is independently worded from the public publisher account, without book content.
- The application bundles unmodified Manrope and IBM Plex Mono with their SIL Open Font License texts and source hashes in `static/fonts/README.md`. The documentation uses system fonts. React and other installed dependencies retain their package licenses; the lockfile identifies exact resolved versions. Generated bundles retain esbuild's legal comments.

## Excluded from publication

Private runtime roots, personal vaults, original notes, credentials, profiles, SQL databases, screenshots, logs, source maps, cached feeds, existing Git metadata and the supplied publisher cover are excluded. The publisher cover had no documented redistribution license in this project. It remains only in ignored local exclusions and recoverable working history; the publication tree does not include it.

## External references

Catalog APIs, live camera links and resource sources are attributed external services, not assets licensed by this repository. Lookup and live media are explicit actions. The application makes no claim that a catalog record is infallible or that an external stream is always available.
