# How to be human

A fictional learning project about attention, listening, uncertainty and asking for help. It is an everyday practice curriculum, not clinical advice or a claim about the owner.

## Curriculum

1. Paying attention: observe one ordinary moment before explaining it.
2. Listening: ask a question and let the other person finish.
3. Not knowing yet: describe what you know, what you assume and what you still wonder.
4. Being in company: make a small, clear request and allow a different answer.

## Weekly rotation

| Day | Practice |
| --- | --- |
| Monday | Notice one detail |
| Tuesday | Listen without preparing a reply |
| Wednesday | Make room for uncertainty |
| Thursday | Practise a small request |
| Friday | Ask one open question |
| Saturday | Walk and observe |
| Sunday | Review one useful moment |
