# Review personal-os before publication

Run a read-only review of the named release candidate and the exact artefact. Do not push, release, change visibility or rewrite history.

Check the current tree, reachable history, config examples, generated files, archive, assets and source maps for secrets and personal data. Report categories and paths, not contents. A secret scanner does not replace a manual check for indirect identifiers. A real credential needs revocation; never copy it into the answer.

Check the LICENSE, provenance and attribution, and that there are no private personas, memory, user profiles or real notes. Fixtures and personal scenarios must be fictional; a public bibliographic Library record is allowed only with its source and without the text of the book. A cold install and the main scenario work without AI. An empty scope never extends to neighbouring vaults.

Compare the default menu with `src/navigation.js`: Movements: Main, Today, GTD, Calendar, Work; Home: Home, Health, Library; Garden: Career, Learning, Future; AI Agent; utilities Graph, Projects, Review, Setup. `src/navigation.js` is the authority for this order. Check the depth of each workflow and that the documentation is truthful: local calendar CRUD, read-only iCal and RSS with explicit refresh are real; Google OAuth, API writes and medical sources are not claimed.

Check user areas and project create, edit, display-title rename, archive and restore without code changes. For a new domain or page adapter, check navigation, fictional fixtures, empty and error states, scope tests and permissions. Task, project, `Inbox.md` and review writes need preview, freshness and undo. Check that page records persist as Markdown under `Records/` and `Settings/`, that SQLite holds no only copy of user data, that a reload and restart keep records, and that an external edit of a record file is detected. Check the storage migration report, backup location (`private/storage-backups/`, never `/tmp`) and rollback.

Check the observation flow: candidates excluded from retrieval, human-only acceptance, a matching review required for an accepted claim to be selectable, and model vault writes refused without `ALLOW_MODEL_VAULT_WRITES`.

Run build, check, meaningful tests and demo desktop and mobile QA. Check lighting phases, manual override, reduced motion, keyboard focus and that active projects stay visible. Time must never decide health, energy, mood or commitments.

Check explicit AI send consent, selected-context freshness, export and import limits and that no transcript is stored automatically. A loopback endpoint does not prove offline inference by an external daemon. Compare README and docs with actual behaviour.

Rhythm is a day chart with five synthetic anchors, the current time in the chosen timezone and gentle motion that can be paused. Do not add a Japanese calendar, glyphs or an invented scientific origin. Respect reduced motion and the static scene. Anchor choice and manual Energy/Mood do not change with lighting; the clock shows time, not the state of the person.

Check the three synthetic vaults, the separate explicit real-root settings, and that there is no silent discovery, ingestion or private persona. An agent query runs local SQLite FTS5 keyword retrieval over the selected notes and records only, with vault, path and line references in the preview. It is not embeddings, semantic search or a memory of the person. Every provider send needs fresh context and explicit consent. Databases, private iCal URLs, profiles and live notes are absent from the archive. Local calendar events are Markdown records. Feeds are user-supplied read-only iCal or RSS/Atom URLs; definitions live in `Settings/sources.md`, private URLs in local credential storage outside Git, fetched items in a SQLite cache. Adding or listing a source does not fetch; only an explicit Refresh does, and a failed refresh keeps the cache. No Google OAuth, API writes or background polling. Check SSRF, redirect, timeout and size limits.

Setup holds the Home programme (title, start date, length 1-52 weeks), focus length (default 60, 1-180 minutes), work hours, news and calendar visibility, news limit, shortcuts and lighting. ⌘K / Ctrl K captures a note or task through a Markdown preview, ⌘⇧K / Ctrl Shift K searches pages, Alt 1-9 navigates. The cool blue-gray palette stays in every lighting phase. Check Escape, focus and IME, and that there are no Japanese glyphs or calendar.

Return passed and unmet gates with evidence. Mark checks you could not run as not done. The review prepares a decision for the owner; it does not authorise publication.
