# Set up personal-os

Help me install personal-os and adapt it to my work. Read the applicable project instructions, README and `docs/demo-pages.md`. Say which actions your environment can actually perform. Work only in the project I chose; never search the computer for personal vaults.

Start with a short interview: the outcome I need, habits that already work, my areas and projects, useful pages, allowed sources, language, time and lighting. Ask one or two questions at a time; any answer may be skipped. A fully synthetic demo without my notes is a valid start.

Keep the default menu: Movements: Main, Today, GTD, Calendar, Work; Home: Home, Health, Library; Garden: Career, Learning, Future; AI Agent; utilities Graph, Projects, Review, Setup. `src/navigation.js` is the authority for this order. AI Agent is a generic assistant name without a private persona. Keep the depth of each workflow, including Home weeks and the Career and Learning sections; never present fictional examples as my data.

Create, edit, rename the title of, archive or restore my projects through the existing Projects page, and manage areas in Setup. That needs no code change. A new domain or page needs its own agreed logic, source adapter, navigation entry, fictional fixtures and tests. Never restructure a vault to suit the app.

Records are Markdown. A save writes the canonical `.md` file in the Main Vault before it reports success: page records under `Records/`, preferences under `Settings/` (see `docs/storage-contract.md`). This covers Work sessions, completed work, time blocks and meeting preparation; Home weeks; Health practices and sleep; Library; Career and Learning records; Future exploration; Main decisions, context, priorities, garden and practices; manual Energy/Mood check-ins; and local calendar events. SQLite holds only the retrieval index, revision bookkeeping, feed and native calendar caches and technical state; deleting it loses no record. The selected Rhythm anchor, a running focus countdown, unsent capture drafts and unsaved AI conversations stay in page memory. A record save is refused when its file changed outside the app; reload, then edit. Task, project, `Inbox.md` and weekly-review edits keep preview, freshness check, apply and session undo.

Main Vault, Person-self-model and AI-Model use only explicitly configured roots (`VAULT_PATH`, `PERSON_SELF_MODEL_PATH`, `AI_MODEL_PATH`); never search for other vaults. Model vaults hold reviewed observations: a candidate in `_inbox/` cites hashed source notes and stays out of retrieval until a person accepts, defers or rejects it on the Review page. Acceptance writes a review to `Reviews/` and the claim to `Accepted/`; only an accepted claim with a matching human review can be selected as agent context. An agent cannot draft or accept candidates. Model vault writes need `ALLOW_MODEL_VAULT_WRITES=true` outside the demo.

An agent query runs local SQLite FTS5 keyword retrieval over the selected notes and records only, with vault, path and line references in the preview. It is not embeddings, semantic search or a memory of the person. Every provider send needs fresh context and explicit consent.

Local calendar events are Markdown records. Feeds are user-supplied read-only iCal or RSS/Atom URLs; definitions live in `Settings/sources.md`, private URLs in local credential storage outside Git, fetched items in a SQLite cache. Adding or listing a source does not fetch; only an explicit Refresh does, and a failed refresh keeps the cache. No Google OAuth, API writes or background polling.

Setup holds the Home programme (title, start date, length 1-52 weeks), focus length (default 60, 1-180 minutes), work hours, news and calendar visibility, news limit, shortcuts and lighting. ⌘K / Ctrl K captures a note or task through a Markdown preview, ⌘⇧K / Ctrl Shift K searches pages, Alt 1-9 navigates. The cool blue-gray palette stays in every lighting phase.

Rhythm is a day chart with five synthetic anchors, the current time in the chosen timezone and gentle motion that can be paused. Do not add a Japanese calendar, glyphs or an invented scientific origin. Respect reduced motion and the static scene. Anchor choice and manual Energy/Mood do not change with lighting; the clock shows time, not the state of the person.

Show a short plan and the expected result. Once I agree, carry out the needed reversible local steps without asking again. Code, note reads, note writes, network and publication are separate permissions. Do not connect cloud services, publish, or carry over anyone's identity, memory or private examples without the matching permission. Finish with the checks you ran and the limits that remain.
