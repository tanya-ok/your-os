# Run my weekly review

Help me review the week from the chosen sources and the current allowed scope. Where data is missing, use my answers. Never search other vaults, private journals or past conversations automatically.

Start with what needs attention now. Help me clear the inbox, sort Next, Waiting and Someday, and choose current projects for my areas. Separate fact from assumption. Count only the time and energy I report myself; a Rhythm anchor, Energy 1..5 and Mood 1..10 can be manual guides, never a diagnosis or a clock-based inference.

Clarify which projects to create, edit, rename by title, archive or restore. Use the Projects preview and apply flow with freshness check and undo; the file ID stays stable. A new area can be added in Setup. A new domain or page needs its own adaptation of logic and navigation, not a hidden widening of vault reads.

Do not carry every unfinished task forward mechanically. Ask what is still a commitment and what to postpone, cancel or keep as reference. Do not hide active projects because of evening lighting.

Return a short review and proposed changes. Apply task, project and review edits only inside the agreed scope through the safe flow. Page records (Work, Home, Career, Learning, Main, Health, Library, check-ins) are Markdown files under `Records/`; the Home programme review is a record and is not merged into `Weekly-review.md` automatically. If an observation about me or about the agent comes up, it can become a candidate in a model vault only when I enter it myself on the Review page; I decide whether to accept it. Do not send data to an external model or save the transcript without separate permission. Without tools, prepare text for manual transfer. Never carry over a private persona or someone else's memory.

Rhythm is a day chart with five synthetic anchors, the current time in the chosen timezone and gentle motion that can be paused. Do not add a Japanese calendar, glyphs or an invented scientific origin. Respect reduced motion and the static scene. Anchor choice and manual Energy/Mood do not change with lighting; the clock shows time, not the state of the person.

If you use an agent query, choose the needed notes and records from the configured vaults and check the snippets, their origin and lines. An agent query runs local SQLite FTS5 keyword retrieval over the selected notes and records only, with vault, path and line references in the preview. It is not embeddings, semantic search or a memory of the person. Every provider send needs fresh context and explicit consent. Keyword results are not a complete search or a verified memory of me. Calendar and feed content can be a stale cache: check publication and fetch dates and errors, and do not refresh over the network without an agreed action.
